# 🎮 GameHub

**GameHub** is a feature-rich Android gaming application developed in **Kotlin** that brings together seven engaging mini-games within a single, intuitive platform. Built using the **MVVM architecture**, the app focuses on clean code organization, responsive UI, and an enjoyable user experience while demonstrating Android development best practices.

The application features score tracking, timers, animations, leaderboards, and Firebase integration to provide a seamless gaming experience. It also incorporates REST API integration and Broadcast Receivers, showcasing practical Android development concepts beyond game logic.

## ✨ Key Features

- 🎮 Seven interactive mini-games in one application
- 🏆 Score tracking and leaderboard system
- ⏱️ Timers, animations, and game progress management
- 🔥 Firebase integration for data storage and user management
- 🌐 REST API integration
- 📡 Broadcast Receivers for Android event handling
- 🏗️ MVVM architecture for maintainable and scalable code
- 📱 Responsive Material Design user interface

## 🕹️ Included Games

- ⚡ Rapid Fire Trivia
- 🧠 Memory Match
- 🔤 Word Quest
- 🎹 Piano Tiles
- 🟦 Rapid Tile Challenge
- 🧩 Photo Puzzle
- 🌈 Neon Dash Runner

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** XML, Material Design, RecyclerView
- **Backend:** Firebase
- **Networking:** REST APIs
- **Android Components:** Broadcast Receivers, Intents, Activities & Fragments
- **Tools:** Android Studio, Git
